About this page静态托管能做什么 / 不能做什么
01 · 真实数据

五个案例取自 Telecom Italia 米兰网格活动量（ODbL 1.0），时刻与网格号可追溯到原始行； 曲线、邻域热力与台账数值均由后端脚本算出后导出，页面不做二次加工。

02 · 规则引擎

结论等级不是模型写的：三条判据（幅度 / 持续 / 空间局域）命中几条，就给对应等级； 点击「复核判据」看到的点亮顺序，就是引擎的计算顺序。

03 · 可回溯

每条证据可展开为工具原始返回（JSON），并带 provenance：文件、行号、时区、聚合粒度。 结论旁边写明降级理由，而不是只给一句话。

What this page cannot do静态托管的边界
  • 不能运行 Python 后端：本页没有模型调用，也没有实时数据读取。
  • 不能切换任意网格或时间：只能看已经导出的 5 个案例。
  • 不能写 trace：运行记录保存在本地 outputs/traces/，不在浏览器里。
How to run the real thing三条命令
pip install -r requirements.txt
uvicorn backend.main:app --reload
# open http://127.0.0.1:8000
